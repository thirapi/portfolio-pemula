# Portfolio Pemula

Template website portfolio sederhana yang dibuat **hanya dengan HTML dan CSS** — tanpa framework, tanpa JavaScript, tanpa instalasi apa pun. Cocok untuk kamu yang baru belajar web dan ingin punya portfolio sendiri.

## ✨ Fitur

- Hanya 2 file utama: `index.html` dan `style.css`
- Kode diberi komentar berbahasa Indonesia
- Responsive (rapi di HP maupun laptop)
- Warna tema mudah diganti lewat variabel CSS
- Bagian: Navbar, Hero, Tentang, Keahlian, Proyek, Kontak, Footer

## 🚀 Cara Pakai

1. **Clone** repository ini:
   ```bash
   git clone https://github.com/thirapi/portfolio-pemula.git
   ```
2. Buka folder `portfolio-pemula`.
3. Klik dua kali `index.html` — website langsung terbuka di browser.

Tidak perlu install apa-apa!

## ✏️ Cara Mengubah

| Ingin mengubah...      | Buka file    | Cari bagian                         |
|------------------------|--------------|-------------------------------------|
| Nama, teks, deskripsi  | `index.html` | Ganti tulisan `Nama Kamu`           |
| Warna tema             | `style.css`  | `:root` di paling atas (`--warna-utama`) |
| Foto profil            | `index.html` | Ganti `<div class="foto">NK</div>` dengan `<img src="foto.jpg" alt="Foto saya" class="foto">` |
| Daftar proyek          | `index.html` | Salin/hapus blok `<article class="kartu">` |
| Email & sosial media   | `index.html` | Bagian `KONTAK`                     |

## 📁 Struktur File

```
portfolio-pemula/
├── index.html   → struktur & isi halaman
├── style.css    → tampilan (warna, ukuran, tata letak)
└── README.md    → panduan ini
```

## 🌐 Online-kan Gratis dengan GitHub Pages

1. Fork / upload ke repository GitHub milikmu.
2. Buka **Settings → Pages**.
3. Pada *Source*, pilih branch `main` lalu klik **Save**.
4. Tunggu sebentar, website kamu akan online di `https://username.github.io/portfolio-pemula/`.
